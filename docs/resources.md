# Further Reading

## References
- **cppreference.com**: the definitive reference for the language and standard library.
- **C++ Core Guidelines**: https://isocpp.github.io/CppCoreGuidelines (Stroustrup & Sutter).
- **Compiler Explorer**: https://godbolt.org. See the assembly your code produces and try different compilers.
- **C++ Insights**: https://cppinsights.io. Shows what the compiler generates for lambdas, range-for, etc.

## Books
- *A Tour of C++* (3rd ed.), Bjarne Stroustrup: a concise overview of modern C++.
- *Effective Modern C++*, Scott Meyers: 42 items on C++11/14 that still apply.
- *C++ Concurrency in Action* (2nd ed.), Anthony Williams.
- *Professional C++* (6th ed.), Marc Gregoire: a thorough C++20/23 reference.
- *Game Programming Patterns*, Robert Nystrom: free online at gameprogrammingpatterns.com.

## Libraries used in this repo
- cpp-httplib: https://github.com/yhirose/cpp-httplib
- nlohmann/json: https://github.com/nlohmann/json
- libpqxx: https://github.com/jtv/libpqxx
- doctest: https://github.com/doctest/doctest
