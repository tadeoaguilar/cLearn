# Further Reading

## References
- **cppreference.com**: the definitive reference for the language and standard library.
- **C++ Core Guidelines**: https://isocpp.github.io/CppCoreGuidelines (Stroustrup & Sutter).
- **Compiler Explorer**: https://godbolt.org. See the assembly your code produces and try different compilers.
- **C++ Insights**: https://cppinsights.io. Shows what the compiler generates for lambdas, range-for, etc.

## Books
- *A Tour of C++* (3rd ed.), Bjarne Stroustrup: a concise overview of modern C++.
- *Effective Modern C++*, Scott Meyers: 42 items on C++11/14 that still apply.
- *C++ Concurrency in Action* (2nd ed.), Anthony Williams.
- *Professional C++* (6th ed.), Marc Gregoire: a thorough C++20/23 reference.
- *Game Programming Patterns*, Robert Nystrom: free online at gameprogrammingpatterns.com.

## Libraries used in this repo
- cpp-httplib: https://github.com/yhirose/cpp-httplib
- nlohmann/json: https://github.com/nlohmann/json
- libpqxx: https://github.com/jtv/libpqxx
- doctest: https://github.com/doctest/doctest

## C, embedded and assembly (part 5)
- *The C Programming Language* (2nd ed.), Kernighan & Ritchie: short and still the classic.
- *Modern C*, Jens Gustedt: C17/C23 done right. Free PDF from the author.
- *Effective C* (2nd ed.), Robert Seacord: secure, correct C.
- *Making Embedded Systems* (2nd ed.), Elecia White: architecture for firmware, from someone who ships it.
- *The Definitive Guide to ARM Cortex-M3 and Cortex-M4 Processors*, Joseph Yiu.
- STM32F401 reference manual (RM0368) and the Nucleo-F401RE user manual (UM1724), free from st.com.
- *Computer Systems: A Programmer's Perspective*, Bryant & O'Hallaron: machine code, linking, memory.
- System V AMD64 ABI and the Arm AAPCS64: the official calling-convention documents.
- Felix Cloutier's x86 reference (felixcloutier.com/x86) and Arm's A64 instruction reference.

## Unreal Engine
- Official docs: https://dev.epicgames.com/documentation/en-us/unreal-engine
- Unreal coding standard: https://dev.epicgames.com/documentation/en-us/unreal-engine/epic-cplusplus-coding-standard-for-unreal-engine
